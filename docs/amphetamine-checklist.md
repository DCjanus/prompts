# macOS Amphetamine 配置检查

这是一份交给 Codex 使用 Computer Use 执行的检查说明，不是 skill。适用于 William Gustafson 开发的 [Amphetamine](https://apps.apple.com/us/app/amphetamine/id937984704)；不要混淆同名软件或独立辅助程序 Amphetamine Enhancer。

## 用途与所需配置

MacBook 在合盖且没有活跃外接显示器时，通常会进入睡眠。这不利于 Codex 长任务持续运行，也不利于 Codex daemon 随时接收手机端远程控制。因此使用 Amphetamine，在插电时保持系统唤醒，拔电后恢复原有睡眠行为。将检查说明放在 prompts 仓库，便于在多台 macOS 设备上交给 Codex 检查相同配置。

为避免异常耗电，采用保守配置：保留 macOS 原有自动休眠设置，仅在接通外部电源时由 Amphetamine 阻止休眠，使用电池时解除干预。

达成这个目标需要以下配置：

1. 开启 Amphetamine 的登录启动和触发器功能。
2. 设置一个插电触发器，唯一条件为“电源适配器已连接”；不依赖正在充电、外接显示器或应用运行。
3. 在这个触发器中允许显示器睡眠，但禁止合盖时系统睡眠。
4. 关闭启动或唤醒后自动开始额外会话，避免其他触发器或手动会话干预电池模式。
5. 保持硬盘唤醒和自动移动光标等额外功能关闭。
6. M 系列 MacBook 还需检查 Power Protect 的安装状态，处理合盖模式下电源切换的已知问题；无法从界面确认时如实记录。

本说明只检查 Amphetamine 配置，不包含 Codex daemon 自身的安装、启动或远程连接设置。

## 可直接使用的任务提示词

> 请读取 `~/Code/prompts/docs/amphetamine-checklist.md`，使用 Computer Use 检查本机 Amphetamine 的设置是否符合文档目标。默认只检查，不修改设置，不安装辅助组件，不开始或结束会话。报告每项实际观察到的值、差异和未确认项。任务范围仅限配置检查。

## 目标行为

- 接通外部电源时，系统持续保持唤醒，包括合盖、没有外接显示器、没有后台任务运行的情况。
- 屏幕可以按原有设置熄灭；无需一直亮屏，也无需模拟鼠标活动。
- 使用电池时，Amphetamine 不干预原有睡眠行为，效果应如未安装它。拔电不要求立刻睡眠，而是解除保持唤醒，让系统按原有规则处理。
- 接受外接硬盘省电休眠，以及下一次访问时的短暂唤醒延迟；不启用 Drive Alive。

这里的保持唤醒针对自动睡眠和合盖睡眠。手动睡眠、退出登录、重启、关机或异常状态需分别判断，不能承诺任何情况下“绝对不休眠”。Amphetamine 需要在用户会话中运行，登录启动不等于登录前就能生效。

## Computer Use 操作约定

1. 按当前 Computer Use 工具文档初始化，通过 UI 获取应用和读取窗口。不要用终端、AppleScript 或直接读写偏好文件替代用户要求的界面检查。
2. 优先选择 `/Applications/Amphetamine.app`。本次设备上，Bundle ID `com.if.Amphetamine` 同时匹配主程序和登录辅助程序，直接使用 Bundle ID 会报歧义。
3. 如果主程序没有设置窗口，读取可能超时。尝试正常打开设置；连续失败时，请用户点击菜单栏 Amphetamine 图标并打开“设置 / Preferences”，再重新读取。不要把超时解释成未安装或配置错误，也不要无限重试。
4. 每次操作后读取新的 UI 状态，再决定下一步；不复用其他设备或旧状态的控件编号。勾选状态看实际值，必要时用截图交叉确认。
5. 双击触发器进入编辑窗口属于检查。检查后用“取消”退出，不点“保存”；其他设置页只读取，不切换复选框。
6. 中文和英文标签、不同版本的界面可能不同。按选项含义核对，遇到含糊翻译时保留原文，查帮助或官方说明；无法确认就标记未确认。

## 设置检查清单

| 位置 | 检查项 | 预期 |
|---|---|---|
| 通用 / General | 开机或登录时运行 Amphetamine | 开启 |
| 通用 / General | 启动 Amphetamine 时自动开启会话 | 关闭，避免产生与供电条件无关的会话 |
| 通用 / General | 从睡眠中唤醒后自动开启会话 | 关闭 |
| 触发器 / Triggers | 启用触发器 | 开启 |
| 触发器列表 | 启用的规则 | 仅有插电保持唤醒规则；其他启用规则须逐一检查，不能影响电池模式 |
| 插电触发器的条件 | 电池 & 电源适配器 / Battery & Power Adapter | 仅当电源适配器已连接；不是“正在充电”，不附加电量条件 |
| 插电触发器的条件 | 显示器、应用、下载、CPU 等条件 | 无；这些条件不能成为保持唤醒的前提 |
| 插电触发器的附加选项 | 允许显示器睡眠 / Allow display sleep | 开启 |
| 插电触发器的附加选项 | 合盖时允许系统睡眠 / Allow system sleep when display is closed | 关闭 |
| 插电触发器的附加选项 | 允许屏幕保护程序运行 | 记录当前值；不作为系统保持唤醒的判定依据 |
| 硬盘唤醒 / Drive Alive | 启用硬盘唤醒 | 关闭 |
| 系统控制 / System Control | 自动锁屏、自动移动光标等 | 不启用额外干预；锁屏仍由原有系统设置控制 |
| 会话默认设置 / Session Defaults | 低电量结束会话及其他全局结束条件 | 记录当前值与适用范围，确认不会意外结束插电触发会话 |
| 菜单栏当前会话 | 正在运行的会话类型及来源 | 插电时应由插电触发器保持唤醒；没有与条件无关的手动会话 |

会话默认设置与某个触发器的附加选项须分别读取。默认时长“无限期”本身不会主动开始会话，也不能证明拔电后仍会保持唤醒；但手动启动的无限期会话可能影响电池模式。不能只看触发器正确，就跳过当前会话检查。

本次 Amphetamine 5.3.2 中文 UI 中，触发器窗口出现“当显示器睡眠时允许系统睡眠”，会话默认页出现“显示器关闭模式：当显示器关闭时允许系统睡眠”。这类翻译易与普通屏幕熄灭混淆，检查时应核对它是否对应英文的 `display is closed`（合盖），不要仅按“睡眠”二字推断。

## Apple Silicon 与辅助组件

先通过设备信息界面确认芯片型号和 macOS 版本，并记录 Amphetamine 版本。MacBook 检查合盖；台式 Mac 将合盖标记为不适用。

对 M 系列 MacBook，检查是否有 Power Protect 已安装的界面状态或相关提示。作者说明，合盖模式在连接或断开外部电源后可能异常，[Power Protect](https://github.com/x74353/Amphetamine-Power-Protect) 用于处理这一问题。它与 [Amphetamine Enhancer](https://github.com/x74353/Amphetamine-Enhancer) 是不同的辅助组件。

没有看到提示不能证明已经安装。若 UI 无法确认，报告“Power Protect 安装状态未确认”。默认检查任务不安装组件；发现缺失时说明下一步所需操作，等待用户授权。

## 输出要求

用简短结论开头，给出以下记录，便于不同设备比较：

- 检查日期、设备型号、芯片、macOS 版本、Amphetamine 版本；读不到就写未确认。
- 表格：检查项、实际值、预期值、结果（符合 / 不符合 / 未确认 / 不适用）。
- 当前会话来源、其他启用触发器、Power Protect 状态。
- 差异及建议修正；只检查时明确“未修改设置”。若用户另行授权修正，修改后重新读取并记录具体变更。
- 结论只回答配置项是否符合目标。关键设置未读到时列为未确认，不要笼统写全部符合。

## 参考基线

2026-10-08 在一台装有 Amphetamine 5.3.2 的设备上，通过 Computer Use 观察到：触发器启用，仅有启用的“电源连接”；条件为“仅当电源适配器已连接时”；触发器允许显示器睡眠、不允许合盖系统睡眠；开机运行开启；启动和唤醒自动开始额外会话均关闭；硬盘唤醒关闭。

该次未确认当前是否有手动会话及 Power Protect 安装状态；其他设备检查时仍需读取本机实际值。
