# 文档边界

按文档的目标读者和任务选择内容，只写会影响其使用、操作、判断或排障的信息；代码或配置发生变化，不自动意味着需要扩写文档。

- README 只承担项目简介、快速上手和资料导航，用最少的步骤与示例让读者开始使用。详细使用指南、完整参数说明、配置参考和技术说明放入专门文档，README 按需链接，不展开长篇使用教程。
- CONTRIBUTING.md 和 RELEASE.md 分别保留贡献与发布所需的准备、操作和必要约束。CI job 拓扑、缓存策略、附件上传机制等实现细节，只有影响该读者的必要操作或判断时才提炼写入，不复述配置。

实现细节维护在对应代码、脚本、配置及必要的就近注释中；确需解释设计取舍时放入相关设计文档，避免在无关文档中重复维护同一事实。
