# 视图与团队设置

调整个人展示入口、团队状态、标签或自动关闭/归档规则时读取。参数从对应命令组的 `--help` 探索；不要为整理导航修改任务归属或删除 Team。

| 需求 | CLI 入口 |
| --- | --- |
| 查找团队、核对团队配置 | `team` |
| 自动关闭与自动归档 | `team automation` |
| 创建或修改工作流状态 | `workflow-state` |
| 管理标签 | `label` |
| 创建或调整 Custom View | `view` |
| 布局、排序及个人展示偏好 | `view preferences` |

## 团队、状态与标签

创建状态或标签前按目标范围精确查重。标签区分 Team 与 workspace；删除标签会移除已有 Issue 的关联，先核对影响范围。

工作流状态使用 Linear 原生类型，不能把显示名称当作类型。Linear 保留的 `Duplicate` 状态不可更新。

自动关闭与自动归档会影响团队中的既有事项，修改前读取当前配置、核对周期和关闭目标状态。周期单位为月；禁用使用对应的显式关闭选项，不用猜测零值的含义。

## 视图与个人偏好

Custom View 只是展示入口，不改变 Issue 对团队的归属。过滤器使用官方 `IssueFilter` JSON；不要自创字段或语法。若不确定现有字段，按 [API 能力与扩展](api.md) 核对 schema。

个人偏好通过 `view preferences get/update` 读取或调整。更新合并现有显式值，JSON `null` 删除覆盖；先读取实际值，不把继承的有效值误当个人设置。

删除 View 前确认仍有可用入口；不要通过删除或 retire Team 整理导航。特定工作场景的布局和状态约定由对应 skill 补充。
