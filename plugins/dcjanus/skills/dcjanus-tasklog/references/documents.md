# 长期文档

保存、搜索或更新运维手册、设备配置差异及其它长期参考资料时读取。使用 Linear 原生 Document，让 Issue 继续承载需要推进的目标。

## 选择容器与查重

跨项目共享资料放 Team 文档，项目专属资料放 Project 文档。团队不明确时按入口约定确认；不要为了保存资料另造一个待办。

使用 `document search` 查找候选，用 `document get` 读取完整正文。同一容器中的同名文档需要核对，包括归档记录；不能因列表或搜索未展示正文就判定资料缺失。列表和搜索的分页处理遵循入口约定。

## 更新正文

通过 `--content-file` 提供 UTF-8 Markdown。更新会替换完整正文：先读取当前文档，保留仍有效的内容，再预览替换结果；空文件表示清空正文。

保存稳定、可复用的资料和必要来源，不把执行日志整段复制进文档，不存凭据。写后回读实际标题、容器和正文；如资料暴露了新的后续目标，另建 Issue 引用文档，不把它藏在资料中当作已跟进。
