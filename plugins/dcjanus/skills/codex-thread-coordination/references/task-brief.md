# 任务简报

派工时填入已核实事实，未知项写明待确认；不要把模板中的占位项或未准备的 ID 发给执行工具。简报是用户可见的自然语言，不是新的工具 schema。

```markdown
目标与范围：
改动与契约归属：真实路径 / 输入输出契约 / 与其它任务的重叠及集成人
禁止范围：
原始人类授权来源：请求原文/所在会话及可读取证据；分别列出创建会话、发送消息、回复消息、commit/push、PR/MR、本地集成、正式合入和历史改写的授权与未授权项；注明可复用授权覆盖的会话、方向与范围，缺项在派工前尽早一起澄清
主会话：threadId / host
工作会话：ready threadId / host；queued 时仅记录 clientThreadId 与待准备状态
仓库：权威源码绝对路径 / 已分配 worktree / branch
基线：已核实 base/ref / SHA / 核实时间
交付方式：本地变更 / 独立 PR/MR / 堆叠分支 / 仅工作区修改；最终发布分组与责任
前置依赖：ref / 固定 SHA / 可消费条件及验证缺口 / 实际合入状态 / 开始条件
集成策略与权限：本地集成方式与责任 / 最终目标分支与合入权限 / 父子关系及同步责任；不把消费前置等同正式合入
调度依据：当前就绪任务 / 关键路径及可解除的阻塞 / 并行度与资源、验证、审查容量的依据
验收条件：可观察行为、风险路径及所需验证环境
组合验收：跨任务行为 / 集成验证归属 / 在何种已集成状态下执行
模型与推理强度：人类明确指定值及来源，或沿用默认
共享资源：资源 / 是否允许并行 / 当前归属会话 / 使用范围 / 交接条件 / 恢复责任；未分配或争用时先请求主会话协调
交付与写权限：实现、验证、commit、push、PR/MR、通知、本地集成、正式合入各自权限；不自行合入目标
交付位置：worktree/ref/head 与结构化报告，发布时补 PR/MR；通知目标真实 ID / host，未授权或失败时由主会话等待兜底
```

账本可留在当前会话或现有任务文档，不要求新持久化文件或脚本。例如：

| 任务 | 状态/依赖 | ID/host | worktree/branch | ref/head/base、可选 PR/MR | 资源 | last cursor |
| --- | --- | --- | --- | --- | --- | --- |
| A | 验证中/无 | ready ID/local | 绝对路径/分支 | ref/head SHA/base SHA | 排他资源 R，使用完成后恢复并释放 | wait 返回值 |
| B | 等 A 可消费，未正式合入 | 尚未创建 | 待固定父版本 | 待核实 | 无 | 无 |

若 B 也需要排他资源 R，先向主会话请求协调，继续不依赖 R 的工作；主会话确认 A 恢复并释放后，再将 R 交接给 B。独立 worktree 不解除其它资源的排他约束。B 按简报所记录的消费条件与固定前置版本执行；若项目要求主线前置，PR/MR 仅获批或 CI 通过仍不满足实际合入条件。
